Ajustes de ACRCloud

Cómo funciona

  1. Token. En la consola de ACRCloud: Account → Developer → crea un API token. Pégalo en Ajustes.
  2. Bucket. Copia el id o nombre del bucket de tu proyecto (Consola → Buckets). La API exige buckets.
  3. Sube el lote. Cada archivo se sube a ACRCloud (S3 prefirmado), entra en cola y espera resultados.
  4. Resultado. ACRCloud devuelve ai_probability (0–100) y prediction (ai_generated si ≥ 50 %).
  5. Detalle. Pulsa una fila: verás stems (voz/acompañamiento), fuentes IA probables y segmentos.
  6. Cuota. ACRCloud no publica las detecciones restantes. La app mide el audio analizado; escribe los minutos de tu plan en Ajustes para ver el consumo y una estimación de pistas restantes.

La detección es probabilística; acompáñala de revisión humana para decisiones sensibles.
